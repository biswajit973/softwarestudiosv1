# Video Assets

Place your vertical/portrait video reels here (9:16 aspect ratio).

## Expected files:
- `reel-1.mp4`
- `reel-2.mp4`
- `reel-3.mp4`
- `reel-4.mp4`
- `reel-5.mp4`
- `reel-6.mp4`

## Recommended specs:
- **Format**: MP4 (H.264)
- **Aspect ratio**: 9:16 (portrait/vertical)
- **Resolution**: 1080×1920 (Full HD portrait)
- **Duration**: 15–60 seconds
- **File size**: Try to keep under 10MB each for web performance
